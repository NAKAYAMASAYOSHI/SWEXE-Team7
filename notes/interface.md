# 2人の約束

XとYが別々にコードを書いても、名前がずれないようにするための約束。
名前を変えたいときは、PRにして、相方に見せてから変える。

## 担当

| | X | Y |
|---|---|---|
| 担当 | 科目まわり | 課題と見込み |
| 画面 | 科目一覧、科目の登録・編集 | 課題一覧、課題の登録・編集 |

最初の「表を作る作業」は、Xがまとめてやる。

## データ（表と列の名前）

科目は項目をたくさん持ち、項目は課題をたくさん持つ。

| 表 | 入れるもの | 列の名前 |
|---|---|---|
| 科目（Course） | 科目名 | `name` |
| | 合格点 | `pass_score` |
| | 授業の全回数 | `total_classes` |
| | 欠席した回数（最初は0） | `absences` |
| 成績の項目（GradeItem） | どの科目か | `course` |
| | 項目名（課題、小テストなど） | `name` |
| | 割合（％） | `percent` |
| 課題（Task） | どの項目か | `grade_item` |
| | 何回目 | `number` |
| | 締切 | `due_on` |
| | 状態 | `status` |
| | 満点 | `max_score` |
| | 得点 | `score` |

- 空でもよいもの：何回目、満点、得点
- 状態は4つ：未着手、作業中、提出済み、返却済み

## 画面のURL

| 画面 | URL |
|---|---|
| 科目一覧（トップ） | `/courses` |
| 科目の登録・編集 | `/courses/new`、`/courses/:id/edit` |
| 課題一覧 | `/courses/:course_id/tasks` |
| 課題の登録・編集 | `/courses/:course_id/tasks/new`、`/courses/:course_id/tasks/:id/edit` |

## 見込みの出し方

- 今の点：項目ごとに「得点 ÷ 満点 × 割合」を出して、足す。
- あと何点：合格点 − 今の点。
- 休める回数の上限：全回数の3分の1（切り捨て）。

画面に出す文字は4つ。上から順に見て、当てはまった最初のものにする。

1. 欠席が上限を超えた → 「危険（欠席が多い）」
2. あと何点が、まだ点が出ていない項目の割合より大きい → 「危険（届かない）」
3. あと何点が0 → 「合格ライン到達」
4. それ以外 → 「あと○点で合格」

この文字は、Yが作る。Xは、`CreditEstimate.new(科目).label` で受け取って、画面に出すだけ。

## 決まり

- 項目の割合の合計は、100にする（Xが作る）。
- 状態が「返却済み」のときは、得点を必ず入れる（Yが作る）。
- 課題は、締切が近い順に並べる。締切が過ぎていて、状態が「未着手」か「作業中」なら、赤で表示する（Yが作る）。
